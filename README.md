# DAYMARK — личная система ежедневной активности

Готовое статическое веб-приложение для GitHub Pages. Без сборки, сервера, регистрации и платных API.

## Что внутри

- **Мой день:** 7 ежедневных направлений с отдельными метриками и полями.
- **Подъём:** фактическое время, отметка выполнения и сравнение с целью 07:00.
- **Отжимания:** запись каждого подхода, сумма повторений и прогресс к 100.
- **Чтение:** минуты, книга/материал, страницы и заметка; цель — от 60 минут.
- **Новый курс:** минуты обучения, название курса и тема урока; цель — 60 минут.
- **Рабочий план:** список ключевых задач, отметки выполнения, время и итоговая заметка.
- **Домашние дела:** собственный чек-лист и заметка.
- **Идеи:** ежедневная запись и общий банк идей с поиском и сортировкой.
- **Аналитика:** процент выполнения по дням, активные дни, идеальные дни, средние показатели и стабильность по каждой привычке.
- **Данные:** резервная копия JSON, импорт/объединение резервных копий и экспорт сводки CSV.
- Светлая/тёмная тема, адаптация для телефона и планшета.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub, например `daymark`.
2. Загрузи **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `app.js`, `favicon.svg`, `README.md`.
3. Открой репозиторий → **Settings** → **Pages**.
4. В блоке **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. После публикации GitHub покажет адрес сайта вида `https://ТВОЙ-ЛОГИН.github.io/daymark/`.

Фреймворк, Node.js и сборка не нужны. Файл `index.html` находится в корне — GitHub Pages сможет открыть его напрямую.

## Важно о хранении данных

Приложение работает как статический сайт. Все записи хранятся в `localStorage` браузера на том устройстве, где ты их создаёшь. Они не синхронизируются автоматически между компьютером и телефоном и не отправляются на сервер. Для переноса истории скачай JSON-резервную копию в разделе **Мои данные**, затем импортируй её на другом устройстве. Делай резервные копии регулярно.

Данные привязаны к адресу сайта и браузеру. Очистка данных браузера может удалить локальную историю.

## Локальный запуск

Можно просто открыть `index.html` в браузере. Для тестирования через локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.
